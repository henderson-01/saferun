# Contributing

Thank you for your interest in **saferun**!

This project was developed as part of my personal learning journey to explore Docker sandboxing, AI coding agents, and secure development workflows. As such, **I am not accepting pull requests or merges to the `main` branch**.

However, you are more than welcome to:
- **Fork this repository** and adapt it for your own use cases
- Open issues for questions or discussion
- Use this as a reference for building your own sandbox tools

If you build something cool with this, I'd love to hear about it!

Happy coding!
